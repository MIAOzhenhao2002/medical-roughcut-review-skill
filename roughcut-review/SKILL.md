# 医疗短视频粗剪与初检

把每份素材当作“可产生零到多条成片的素材池”，不是天然的一条视频。先选和拆，再对每个成片候选按需删、留、排、改；简单素材不强行走满四步。

## 开始任务

1. 识别素材版本、时间码口径、说话人、问答关系、ASR疑点和已完成阶段；中途接手读取 [intake-and-state.md](references/intake-and-state.md)。
2. 分清四个身份：出镜/内容主体、发布账号、素材中的患者或病例、当前操作者。只有用户明确提供身份与画像时才加载对应资料；未知时使用通用模式，不猜身份。
3. 进入正式“选/拆”，读取 [select-and-split.md](references/select-and-split.md)。输出只能是：`做一条`、`拆成多条`、`有条件做`、`暂存`、`不建议做`。
4. 每个入选方向建立独立候选编号；同一源素材拆条时使用父子关系，如 `S001 → S001-1 / S001-2`。
5. 根据候选复杂度选择后续操作。短而完整的回答可直接“留→改”；明显冗长的内容可“删留合并→排”；无需修音或医学改写时跳过“改”。

只有字幕时照常完成内容判断，但不声称看过动作、表情、影像、口型或听过声音。需要必须补齐的事实、画面或回听才能判断主轴时，标🟥并暂停受影响候选；不阻塞无关候选。

## 显示当前路径

阶段性回复用最短路径说明进度，例如：

```text
当前路径：选/拆 ✓｜删留（合并）●｜排 ○｜改（待判断）
本轮处理：候选 S001-1，压缩重复并锁定必要支撑
暂不处理：标题、精剪素材
下一步条件：确认保留段后进入结构检查
```

`✓` 已完成，`●` 当前处理，`○` 待处理，`—` 本候选无需处理。用户要求直接走完时连续执行；存在真实分岔、关键证据缺失或硬风险才停下来追问。

使用统一动作标记：🟥必须处理或人工确认；🟨建议处理；🟦明确转交后续；🟩保留或已确认。蓝色事项进入对应操作后必须收口为红、黄或绿。

## 按需加载

- 选题价值、成片可行性、拆几条：读取 [select-and-split.md](references/select-and-split.md)。
- 删除、压缩、保留价值：读取 [delete-and-keep.md](references/delete-and-keep.md)。
- 模块、总概、顺序和兑现链：读取 [arrange.md](references/arrange.md)。
- 医学复核、最小修音、成片确认和标题交接：读取 [revise-final-and-handoff.md](references/revise-final-and-handoff.md)。
- 账号路由、团队共用和数据复盘：只有相关时读取 [account-and-learning.md](references/account-and-learning.md)。

阶段切换只保留当前素材、候选方向、已确认项、未解决阻断和必要转交，不重复加载已收口细则。

## 专业能力路由

本Skill已内置专业流程，不依赖其他项目或Skill：

- 模块边界不清时读取 [模块边界](references/module-boundaries.md)。
- 只有新增、改变、存疑或需要核对时效性的实质医学主张，才读取 [医学核查](references/medical-review.md) 并联网核实；纯文字小修和同一已核实主张不联网。
- 克隆、修音、字幕补字、旁白或字卡需要最小改写时读取 [最小改写](references/minimal-rewrite.md)。
- 主线、删留、顺序、医学含义或修音方式存在实质争议，或用户要求对抗式审查时读取 [独立复核](references/independent-review.md)，先盲评当前证据，再比较既有方案和最强反证。

多个Skill同意不等于事实成立。当前素材与医生原话优先，其次为现行权威资料、用户确认的本地证据、去身份化公开样本，最后才是模型一般知识。

## 医学与事实硬边界

- 不编造病例、患者经历、医生原意、现场原声、画面、身份、诊断、治疗、结果或因果。
- 不改变条件、概率、身体部位、诊断范围和治疗选择；不把“可能”改成“确定”或把“改善”改成“治好”。
- 不为传播表现制造素材不存在的冲突、治疗承诺或患者结局。
- 外部检索只使用去身份化问题；不上传患者视频、字幕、姓名、住院号、影像编号或可识别信息。
- 历史表现、同行样本和账号画像只能比较同级候选，不能覆盖医学、隐私、合规、素材权利和AI标识硬门槛。

## 输出与停止条件

- 先给结论，再给能直接落刀的时间码；只解释会改变选择、拆条或医学安全的依据。
- 不按固定时长裁决。十几秒只要问题和兑现完整即可；六七分钟若持续兑现可保留，也可拆成多个独立方向。
- 每条候选只保留一个可复述的核心轴；无法独立兑现的片段不能为了凑条数硬拆。
- “没有硬风险”不等于值得做；没有明确受众、停留理由、内容收益或素材证据时，优先暂存或不做。
- 用户确认后的候选、落刀和医学措辞进入语义锁定；只有新证据或明显更优解释才重开，并说明收益和代价。
- 完成结构后进行一次发布前对抗式检查：最强支持、最强反证、缺失证据、最可能失败点和是否仍值得做。
- 最终只列仍需修改处；无问题时明确说“初检通过，可以进入发布环节”。

主要人工审核门保留两道：入选候选完成结构后的内容确认，以及完成必要修改后的发布前终审。简单且低风险的候选可由用户明确授权合并确认。

## 标题交接

只有用户要进入标题阶段时，按 [标题交接模板](assets/title-handoff.md) 生成去身份化最小交接单。交接最终字幕、核心轴、直接支持事实、禁止误读、医学措辞锁、未解决项与可用画面时间码；不复制完整初检过程，也不替标题项目决定唯一传播方向。

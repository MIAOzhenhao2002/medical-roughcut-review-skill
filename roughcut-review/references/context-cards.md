# 补叙字卡：用可追溯文字补足语境

只在粗剪删减后出现真实信息缺口，或一条简短背景能明显帮助理解人物、时间和现场关系时使用。它是编辑第三方视角的屏幕文字，不是医生原声、普通对白字幕、标题、章节标签、免责声明或B-roll搜索。

## 先修剪辑，再补字

依次判断：补回必要原声或镜头 → 放宽剪口 → 调整相邻顺序 → 只修字幕或短断口 → 补叙字卡或旁白。只要前四种方式能更真实、简洁地恢复理解，就不新增字卡。若一段内容需要连续多张字卡才能成立，返回删留或排处理碎剪与结构，不用文字替坏剪辑兜底。

## 可处理的内容

- `理解补全`：交代被删掉但仍为当前反应、判断或动作成立所需的前因；
- `人物补叙`：用已核实的经历、工作状态或选择帮助观众理解人物，但不神化、贬损或猜测动机；
- `时间语境`：交代日期、时距、阶段、次数或场景转换，让事件关系清楚。

医学解释仍按主Skill的医学核查路由；修复医生已经表达八九成的原句仍按最小改写路由。标题、封面、章节提示、口号、纯情绪金句和视觉包装不进入本参考。

## 多轮处理

首次基线审查只形成候选：记录原版证据、当前粗剪缺口、建议优先动作和必须人工看片的事项。后续V2、V3等复检只更新受变化影响的候选；补回原声、重排或新画面已经解释清楚时，主动取消旧字卡。没有固定复检次数，也不要求每条视频出现字卡。

只有字幕时不得判断人物“生气、委屈、不耐烦”或某个动作已经发生。需要动作、表情、情绪、空间关系或可放字区域才能决定时，标🟦并提出一个最小人工确认项；用户提供视频、截图或明确观察后再收口。人工观察证明画面已能自行交代时，结论应为“不加”。

## 事实与表达边界

- 每句话必须能追溯到当前原素材、用户确认的画面观察或已核实资料；
- 只写可观察事实，不替患者或医生断言心理、故意、责任和因果；
- 不把编辑补叙写成医生说过的话，不制造更强的诊断、疗效或人物冲突；
- 人物履历、工作时长、次数和时间跨度必须有来源；缺证据时标待确认，不用模糊措辞蒙混；
- “通常零到三处”只能作为克制提醒，不是固定数量，也不能成为补满配额的理由。

## 位置与视觉级别

内容人员只决定语义位置和信息权重，不代替精剪做字体、颜色和动效设计：

- `辅助小字`：一句背景，不应抢主字幕和人物表情；
- `中等强调`：当前信息是理解转折所必需，可获得更独立的阅读空间；
- `独立字卡`：只有跨时间、跨场景或需要明确停顿时考虑。

停留区间以正常阅读完成为准，避开人物脸部、患处、检查资料、主字幕和平台按钮。没有实际画面时只写避让需求，不虚构具体坐标。

## 固定输出

```text
当前版本：粗剪V3
对比版本：粗剪V2
位置：V3 00:00:31（原版依据 00:00:42-00:00:58）
类型：理解补全 / 人物补叙 / 时间语境
状态：候选 / 待人工看片 / 最终字卡 / 取消 / 不加
必要性：🟥必须 / 🟨建议
优先动作：补回原声 / 放宽剪口 / 重排 / 字幕修复 / 补叙字卡
缺口或作用：……
依据：原话、画面观察或已核实资料
建议文案：……
新增含义：否 / 是（转相应核查与人工确认）
视觉级别：辅助小字 / 中等强调 / 独立字卡
避让需求：……
下一轮条件：……
```

复检汇报只列本轮新增、修改、取消和仍待确认的字卡；已确认且未受新剪辑影响的项目简要沿用，不整表重做。

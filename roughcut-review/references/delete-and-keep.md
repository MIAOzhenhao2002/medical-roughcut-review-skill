# 删与留：围绕已入选候选压缩

删与留是两个判断动作，不是必须分两轮汇报。素材简单时合并完成；只有争议多、员工需逐刀确认或原粗剪疑似误删时才分开。

## 删：先整段，再细词

删除顺序：

1. 与候选核心轴无关的完整话题或次要分支；
2. 同一内容中的次要例子、解释和流程；
3. 同义重复、无信息问答、寒暄和口癖；
4. 最后才处理停顿、单字和剪口。

不要因为逐字看得太细而保留整段低价值内容。门诊素材缺乏持续画面冲突时，默认更积极压缩重复科普和流程性表达，把时间留给患者真正关心的问题、明确判断、真实取舍、故事进展和可见证据。

仍须保护：必要问答关系、关键前因、患者顾虑和反应、独特事实、画面动作、医学限定词、拆条候选。听不清、价值未明或疑似医学错误的片段先转交，不因处理麻烦直接删除。

## 留：按候选内贡献判断

- 核心：没有它就没有这条视频或无法兑现；
- 必要：让核心成立所需的问题、经历、证据、条件或因果；
- 增益：最有代表性的人物反应、专业细节、金句或画面；
- 可删：不改变理解、信任、情绪或行动的重复与流程。

价值相对于当前候选判断。同一片段在一个候选中可删，在另一个拆条候选中可能是核心。历史流量和账号经验只能帮助比较两个同级候选，不能决定句级删减。

## 输出

每项写“整段删、压缩、保留、补回、待回听”，附版本、时间码、原话和一句理由。先列高影响整段动作，再列必要细剪；给预计时长变化与可能误删点。

若压缩后已经形成完整短回答、无需重排，直接把“排”标为 `—`。若内容仍包含多个模块或兑现位置不清，再进入“排”。

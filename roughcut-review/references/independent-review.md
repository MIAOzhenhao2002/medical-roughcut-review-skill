# 独立复核

只用于会改变主线、删留、模块边界、顺序、医学含义、修音方式或发布安全的争议。普通错字、口癖和显然无争议的小修不启动完整复核。

1. 暂时遮住员工或既有结论，只看当前原素材、版本和时间码。
2. 独立判断真实性、观众理解、医学安全和对当前成片的贡献。
3. 先写独立结论与置信度，再列最强支持、最强反证和缺失证据。
4. 恢复既有方案，比较一致点、冲突点与冲突根因。
5. 按证据层级裁决：当前素材与时间码 → 现行指南 → 用户确认的本地经验 → 去身份化外部方法 → 模型一般知识。
6. 给唯一最终建议；信息不足时只提最小确认问题，不用“都可以”迎合。

复杂争议读取 [独立复核矩阵](review-matrix.md)。

```text
独立结论：保留/删除/重排/待核查（置信度：高/中/低）
最强支持：……
最强反证：……
缺失证据：……
与既有方案的差异：……
问题根因：规则缺口 / 证据不足 / 阶段越界 / 模型迎合 / 执行偏差
最终建议：……
```

多个Skill或多个模型输出相同答案不等于事实成立；如果共享同一来源或同一假设，必须视为相关证据，不能重复计票。

# 最小改写

用于AI修音、克隆声音、旁白、字卡或字幕微调。只澄清医生已经表达且可追溯的含义，不新增病例事实或诊疗结论。

## 允许与禁止

允许修正普通错字、明确主语、补连接词、处理音频断口，或在上下文与医学审校支持下补全已经表达八九成的短句。

不得把“可能”变成“确定”、把“改善”变成“治愈”、扩大诊断范围、改变身体部位、重造因果或新增治疗选择。合成内容不得冒充未经标明的现场原声。

## 执行

1. 保存来源版本、时间码和原话。
2. 写出必须解决的唯一问题；能只改字幕就不做修音，能补一个词就不改整句。
3. 对照 [医学语义锁](semantic-locks.md) 检查条件、概率、因果、身体部位、诊断范围和治疗选择。
4. 生成最小修改句，列出确切增删字词。
5. 若新增、强化或仍存疑，停止普通微调，转 [医学核查](medical-review.md) 和人工或医生确认。
6. 选择原声、字幕、短克隆、旁白、字卡或医生补录；最后才做个别字词的口语自然化。

固定输出：

```text
来源：粗剪版 00:00:21-00:00:27
原话：……
修改后：……
只改了：删除“×”；补“×”
原因：补主语/修ASR/避免绝对化
新增含义：否 / 是（停止，待确认）
采用方式：字幕 / 短克隆 / 旁白 / 字卡 / 医生补录
语义锁：条件✓ 概率✓ 因果✓ 部位✓ 诊断范围✓ 治疗选择✓
```

# 模块边界检查表

## 归为同一模块

- 同一患者问题及其直接回答；
- 同一医学判断的证据、限定条件和结论；
- 同一动作的前因、执行与直接结果；
- 拆开后会丢失主语、指代、条件或情绪转折的连续表达。

## 可以拆分

- 单独成立、指代清楚且不改变因果的独立事实；
- 同一主题下功能不同的两个段落，例如患者经历与医生处理；
- 可独立成条且不依赖前后语境的真实动作或反应。

## 必须转交

- 医学条件、概率或因果尚未核实：转“改”；
- 动作、表情或镜头承接决定边界：转人工看画面；
- 说话人或关键词听不清且会改变模块：阻断并回听。

不要为了凑“起承转合”把同一问答拆开，也不要因为主题相近就把不同病例事实强行合并。

# 独立复核矩阵

| 维度 | 核心问题 | 证据不足时 |
|---|---|---|
| 真实性 | 是否忠于原话、时间码和可见动作 | 不补造，标缺失 |
| 成片价值 | 删除或保留是否真正影响主线与兑现 | 保留到下一阶段复核 |
| 观众理解 | 不看背景能否理解人物、问题和动作 | 补最小上下文，不堆解释 |
| 医学安全 | 条件、概率、因果、部位、诊断和治疗是否准确 | 转指南核查或医生确认 |
| 阶段边界 | 当前问题是否属于正在处理的步骤 | 先答本步，再蓝色转交 |
| 执行可行性 | 员工能否按时间码直接落刀或回听 | 给唯一动作和定位 |

“支持理由多”不等于证据更强。最终裁决看来源质量、与当前素材的直接性和是否能被反证。

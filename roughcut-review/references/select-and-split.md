# 选与拆：先决定值不值得做

“选/拆”是所有候选的必经决策，但不要求单独等用户确认。它决定是否继续投入粗剪时间，不承担医学改写和精剪包装。

## 先找可兑现单元

逐个识别素材中可以独立成立的内容单元。每个单元至少回答四个问题：

1. 谁会关心：具体患者、家属、垂直专业人群或更广受众；
2. 为什么停下：问题、反常识、真实冲突、动作/画面、金句、结果悬念或强情绪；
3. 看完得到什么：答案、判断、故事结果、风险认识、行动建议、医生能力或信任；
4. 素材拿什么兑现：原话、问答、真实经历、检查动作、影像/患处、治疗取舍或结果。

任何一项靠想象补齐，都不能判为“能做”。平台分发只会观察用户行为；判断先从真实人的停留理由和收益出发，再把预期行为写成假设：看完、收藏、转发、评论、关注、主页访问或咨询。

## 候选观察镜头

以下是观察镜头，不是必须齐全的评分表，也不设固定权重：

- 与患者生活直接相关的问题、症状、误区或选择；
- 罕见、直观或反差强的画面与动作；
- 医生或患者能独立成立的金句；
- 患者认知与医生判断之间的真实反转；
- 事情如何发生、如何处理、结果如何的故事链；
- 情感共鸣、家庭关系或社会议题；
- 垂直专业问题、少见术式、影像判断或医生能做什么；
- 可搜索、可收藏、可转发的明确答案。

“情绪、金句、社会议题”只在当前素材真实存在且能兑现时加分，不能为了套模板拔高普通门诊对话。

## 五种结论

- `做一条`：一个核心轴清楚，受众、停留理由、收益和证据闭合；
- `拆成多条`：存在两个以上互不依赖、各自能兑现的核心轴；
- `有条件做`：价值成立，但必须回听、补回原片、确认画面或解决关键风险；
- `暂存`：当前没有足够兑现，但未来可与同题材素材合并；
- `不建议做`：只有流程性话语、重复常识或残缺信息，继续加工仍无明确收益，或必须虚构事实/因果才能成立。

不因为素材长就拆，也不因为素材短就淘汰。拆条必须满足：每条都有独立开头、必要支撑和兑现；拆后不共用一个不可分割的前提；不会让医学条件或因果断裂。

## 最小输出

先给一张候选表：

```text
候选｜结论｜一句核心轴｜目标受众｜停留理由｜最终收益｜关键证据/时间码｜预期行为｜阻断
```

只对入选和有条件候选继续。每条最多给一个主方向；确有两个同等方向时才说明分岔。`暂存`与`不建议做`写一句原因即止，不再进入完整删留排改。

## 选后反证

在投入后续加工前问：

- 去掉病种或医生身份，这段还有具体内容吗？
- 开头承诺的东西，素材后面真的给了吗？
- 观众能否用一句话复述看完所得？
- 价值是否只是“医学上正确”，却没有人会为此停留？
- 是否把同一件事硬拆成多条，或把多件事硬塞成一条？

最强反证成立时降级为有条件、暂存或不建议做。

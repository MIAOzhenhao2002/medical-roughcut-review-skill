# 医学语义锁

逐项比较原话与修改后文案：

| 锁定项 | 必查问题 | 高风险变化 |
|---|---|---|
| 条件 | 原话是否限定某种情况 | 删除“如果、在……情况下、需评估” |
| 概率 | 原话是可能、常见还是确定 | 可能→一定，部分→全部 |
| 因果 | 原话是相关、考虑还是导致 | 相关→导致，判断→确诊 |
| 身体部位 | 部位、侧别、层次是否相同 | 左右混淆、骨与软组织混淆 |
| 诊断范围 | 是症状、怀疑、诊断还是分型 | 疑似→确诊，局部→全身 |
| 治疗选择 | 是建议、可选还是唯一方案 | 可考虑→必须做，改善→治愈 |

任一高风险变化出现时，不再作为普通润色处理；转医学核查和人工/医生确认。
